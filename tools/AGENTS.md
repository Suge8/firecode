# tools：过程组与过程列表

| 文件 | 职责 |
| --- | --- |
| `index.ts` | 包装默认四工具的展示与执行耗时；TUI 会话安装分组，退出释放 |
| `grouping.ts` | 宿主适配：定位聊天容器，安装渲染/鼠标投影，分离全局展示与单工具正文 |
| `group-view.ts` | 从原组件顺序派生轮、过程组与折叠/展开投影 |
| `turn-summary.ts` `turn-clock.ts` | 摘要行渲染；以人类输入为单位累计运行时长（来自 agent_start/agent_end） |
| `machine.ts` | 信封机器消息的一行投影，卡片与展开态共用 |
| `assistant-view.ts` | 思考/正文投影，封装宿主助手组件的内部结构，不重建 Markdown |
| `line.ts` `parts.ts` | 单工具行与着色片段；Master 复用纯渲染部分 |
| `timing.ts` | 真实工具执行耗时，结果渲染取走即释放 |

改分组前核对宿主 `ToolExecutionComponent`、`AssistantMessageComponent`、`Container` 和 TUI 动态引用。
原消息与聊天树不改写、不搬移；渲染与鼠标命中使用同一投影。两档展示直接读取 `getToolsExpanded()`，
不拦截快捷键。过程列表保留原生思考组件与其展开设置；单工具正文仍由宿主工具行持有，其他卡片保持原生行为。

折叠单位是**轮**：只有人类用户消息（不是整条由信封构成的用户消息）开启新的一轮，其左侧画橙色竖条。
轮内的过程节点是宿主组件：助手消息、工具行、CustomMessage，以及机器消息——空闲时 `deliver.ts` 走前门
`sendUserMessage`，模型侧是用户消息，UI 靠信封识别它，与忙时的 CustomMessage 同属过程，不切轮。段内还可能出现整行单色 `Text`——
宿主把 transcript 提示画成 warning、状态行画成 dim，颜色是它唯一给出的语义通道（只折入有工具或思考的段，连同前导
Spacer，warning 计入 `⚠ N`；无摘要行可依附时保持原样，避免为提示凭空造摘要行顶开回复）；错误、混色文本与其余节点（CustomEntry 等）
仍是段边界，同一轮可因此有多个过程组。段尾回复是其后只剩提示与机器消息的最后一条助手消息。

折叠态一轮自上而下：用户消息 → 摘要行 → 最近 `replyLines` 条中间回复各一行灰色首句（更早的折成“+N 条”，
`replyLines=0` 不显示这两类）→ 最后一条回复全文。摘要行运行中是 `flame(1)`、当前动作词、实时计时与读/改/运行/子代理计数；
子代理结果到达（运行中首次出现的机器消息）时用“<名字> 已返回”（失败红色）替换当前动作约 2.5 秒；落定后经 `settleMark` 冷却成
“✓ 时长 · 计数 ▸”。时长只来自 agent 事件，重载恢复的历史轮次未知，省略。动效只经 `flame.ts` 的 `onFrame`：
投影发现有活的摘要或落定过渡才订阅，静止即取消。点击某轮摘要只展开这一轮（状态以该轮用户消息为键），ctrl+o 仍全局展开；
展开态摘要带 ▾，按时间顺序列出工具行、中间回复和机器消息一行“↳ 名字 已返回 · 时长 首句”，CustomMessage（Master 事件卡、review 结果卡等）一律交给自己注册的渲染器，只有整条由信封构成的用户消息才投影成 ↳ 行。

摘要行不铺工具背景色；失败数与提示数是固定标记，计时和计数在窄屏从尾部逐个让位。当前动作词由工具行的
`actionWord` 能力提供，按能力而非类身份选择，避免扩展多次加载产生的 ToolLine 副本不相等；未提供该能力的静态
工具使用通用参数摘要。内置四工具的动作词与目标格式唯一来源是 `actions.ts`（工具行与 Master 活动列表共用）。单工具详情的鼠标事件按裁掉的空行补回坐标后交给宿主。

思考块不计次数或耗时；
明确收到思考时显示“思考中”，空的流式消息只显示“处理中”。纯思考的段留 `✓ 思考` 摘要行，思考结束不消失，
避免回复上移。工具失败数不会被后续成功覆盖，助手的错误、中断和截断诊断始终保留。

宿主在助手 `contentContainer` 的直接子节点中，只把思考包在 MouseRegion。混合消息复用原生正文/错误节点，
独立渲染接收者继承原组件以保留 OSC133 消息跳转与鼠标布局，但只持有自己的 children 和布局缓存。原消息由
宿主失效更新；投影不能调用原生 invalidate 去重建共享子节点，也不复制思考展开状态。

宿主适配只有一个当前所有者，reload 先卸旧再装新；非 TUI 子会话不能安装或卸载主会话投影。借首个助手或
工具插入事件定位聊天容器，找到后立即卸掉发现钩子，不包装 `requestRender`。

只注册默认四工具的包装：注册 grep/find/ls 会改变启用工具集。成功结果未展开时只取长度与耗时，不清洗正文；
错误保留摘要，单工具展开保留原始正文和 edit diff。带背景的单行裁剪用根级 `clip`。
