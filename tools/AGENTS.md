# tools：组摘要与工具列表

| 文件 | 职责 |
| --- | --- |
| `index.ts` | 包装默认四工具的展示与执行耗时；TUI 会话安装分组，退出释放 |
| `grouping.ts` | 宿主适配：定位聊天容器，安装渲染/鼠标投影，分离全局展示与单工具正文 |
| `group-view.ts` | 从原组件顺序派生工具组、组摘要与紧凑列表 |
| `line.ts` `parts.ts` | 单工具行、正文及着色片段；Master 复用纯渲染部分 |
| `timing.ts` | 真实工具执行耗时，结果渲染取走即释放 |

改分组前核对宿主 `ToolExecutionComponent`、`AssistantMessageComponent`、`Container` 和 TUI 动态引用。
工具调用与结果始终归宿主，聊天树不搬移、不另存；渲染与鼠标命中必须使用同一投影。两档展示直接读取
`getToolsExpanded()`，不拦截快捷键。全局 `setExpanded` 对普通工具只关闭正文；点击单工具调原生方法，正文
展开状态仍由宿主工具行持有。其他卡片保持原生全局展开行为。

分组以非空思考（包括折叠思考）、文字和其他可见组件为界；空助手消息不占位。普通内置工具和没有自定义
渲染的工具可合并；图片结果、自定义渲染工具独立保留。组摘要优先展示运行项，失败计数不被后续成功覆盖。

宿主适配只有一个当前所有者，reload 先卸旧再装新；非 TUI 子会话不能安装或卸载主会话的投影。发现聊天
容器只借首个工具插入事件，找到后立即卸掉发现钩子，不包装 `requestRender`。

只注册默认四工具的包装：注册 grep/find/ls 会改变启用工具集。成功结果未展开时只取长度与耗时，不清洗正文；
错误保留摘要，单工具展开保留原始正文和 edit diff。带背景的单行裁剪用根级 `clip`。
