# 宿主私有细节收进一个适配文件并自检形状

过程分组没有宿主提供的聊天投影接缝，只能读宿主组件的私有字段（工具行的 `isPartial`、`expanded`，助手消息的
`contentContainer`、`isStreaming` 等）、改宿主原型（`setExpanded`、`Container.addChild`）、挂空 widget 拿 TUI 句柄。
这些读取原先散在三个文件；宿主某个字段改名后读到 undefined，投影不报错，只会悄悄画错。

改为：所有私有读取与原型补丁只在 `tools/host.ts`，每个读取点校验字段类型。发现聊天容器时先对首批真实实例自检，
不符就不安装分组并提示“过程分组已停用：宿主组件形状变了（字段）”；渲染途中发现不符则整体退回原生显示并提示。
升级 pi 时只审这一个文件，形状变了是明确的提示而不是错画。

替代方案：向上游要聊天容器只读句柄或投影钩子——仍是长期方向，但不能阻塞当前版本。安装时用假实例探测形状——
构造宿主组件需要 TUI 引用且有副作用，改为对首个真实实例自检。

## 后果

摘要行“运行中”只认 busy.ts 一个来源，工具行的 `isPartial` 与助手的流式状态只用来选当前动作的文字；
重载前被打断、残留未完成的工具行不再点火苗。
