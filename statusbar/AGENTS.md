# statusbar：输入框外壳

状态画进编辑器的上下边框横线，没有独立底栏：footer 组件渲染 0 行，只借它拿宿主的扩展状态订阅与主题。编辑器是
`CustomEditor` 子类，只覆写 `renderTopBorder` / `renderBottomBorder`；输入过长滚动出现“↑ n more”时让位给宿主的边框。
会话启动时关闭宿主内嵌的 Working 指示，Working 可见性只在本模块管理（`review/ui.ts` 不再碰它）。

上边框左：会话进行中是 `flame(3)` + “处理中”/“等待 N 个子代理” + 计时（主会话审查期间——等结论、修复、总结——一律不写词，由审查进度的阶段说明，措辞只有一种），歇下那一刻直接是 `settleMark` 的 `✓ 耗时 · 均速`（终态 aborted/error 为红 `✗ 已中断 · 耗时`/`✗ 请求失败 · 耗时`，与摘要行同一写法、终态字样不随窄屏退让，无均速；字形与定格文字同帧出现，0.4 秒内由火焰橙转到终色）并留到下一轮开始，暖光约 1 秒渐隐；
主会话 fire-review 进行中追加审查进度 `<金色转圈点> 审查 第N轮 k/n · m 阻断`（阻断为红；排队、顾问、修复、总结相把计数换成“排队中/顾问介入/修复中/总结中”），这是界面上唯一的审查进度，编辑器上方没有独立审查行。右：watcher 发布的“观察员”、
master 发布的“指挥官”，本模块直接组合发布串，不解析彩色串也不维护启用状态。下边框左：会话标题；右：生效中的预设名（`session/presets.ts` 以 `preset` 键发布的 accent 色名字，不带图标；只改模型与思考档的预设不发布名字，发不发布由预设模块决定，外壳原样显示）、模型/思考档、启用时的
Fast、上下文百分比/容量（`formatTokens`，整数不带小数：`1M`、`200k`）。上下文低占用为灰色，达到既有阈值才警告。

展示标题只属于外壳：正式会话名优先，否则取当前分支首条非空用户文本的完整首句（`format.ts` 的 `firstSentence`，上限 60 列），按终端宽度的截断交给下边框布局；尚无文本显示“新会话”。
会话启动、切树、改名和用户消息开始时更新投影，消息落盘前即可显示，逐帧绘制不扫描历史。不写回会话名，不改变官方会话列表
或终端侧边栏。

`render.ts` 是唯一纯布局入口（`topBorder` / `bottomBorder`，两者与子代理视图输入区共用其中的边框布局 `fitBorder`），按实际 `visibleWidth` 逐级退让，不保存状态：
- 上边框：观察员 → 审查进度逐档缩短（丢阻断数 → 丢票数或阶段，“审查 第N轮”留到最后）→ “处理中”/“等待 N 个子代理” → 审查进度最短档 → 指挥官；
- 上边框三态：指挥官生成中“处理中”；指挥官空闲但有在飞子代理“等待 N 个子代理”，火苗继续转；主会话审查进行中（`BusyView.review`）火苗与计时照常、不写“等待”；歇下后显示落定记录直到下一轮，进行中绝不并排显示上一段的落定记录。状态、起点与落定事实全部来自 `busy.ts` 的 `watchBusy`：计时显示 `now - since`，自会话变忙起连续累计，中途输入与结果唤醒都不重置；落定态的内容是当前分支最近一条人类消息之后的全部轮记录，经 `tools/round.ts` 的 `latestTurnRecord` 按与摘要行同一条合成规则得出（耗时累加、终态取最后、更早的中断追加“中断过 N 次”、多段不给均速），展示片段用 `busy.ts` 的 `roundTexts`。
它只在三个时点算一次并存下合成结果、绘制只读：tools 写入轮记录后在 `ROUND_RECORDED_CHANNEL` 上的发布（不取歇下边沿——那一刻记录未必已写进分支，订阅顺序不定）、`session_start`（重开会话直接显示上一轮，不播落定过渡）、`session_tree`；读分支是整条回溯，不能放进每次按键重绘。外壳不另存累计、不自己记起点、不拼装判断；没有轮记录（工具渲染关闭）就不显示落定态。这是整个界面唯一的实时计时，过程组摘要行不再并排跳一个。
- 下边框：容量 → 预设名 → 标题裁到 8 列 → 模型名逐列裁 → 丢标题；上下文百分比与 Fast 尽量完整保留，连百分比也放不下时退成纯横线。

动效只经 `flame.ts` 的 `onFrame`：仅在回合进行、落定过渡或审查进行时订阅，其余时间时钟停止。审查进度来自 review 发布的占用频道（频道名与 payload 只在 `review/occupancy.ts` 定义）：持有时的 payload 带活的 `progress` 访问器（占用按计数配对，进度变化不能靠重发 true），
外壳每次绘制调用它取阶段、轮次与票数，`active:false` 表示审查结束；审查锁编辑器时由
`review/ui.ts` 包住锁定前的编辑器，取它的上下边框并在中间放一行取消提示，外壳状态因此在审查期间保持可见。
