# statusbar：输入框外壳

状态画进编辑器的上下边框横线，没有独立底栏：footer 组件渲染 0 行，只借它拿宿主的扩展状态订阅与主题。编辑器是
`CustomEditor` 子类，只覆写 `renderTopBorder` / `renderBottomBorder`；输入过长滚动出现“↑ n more”时让位给宿主的边框。
会话启动时关闭宿主内嵌的 Working 指示，Working 可见性只在本模块管理（`review/ui.ts` 不再碰它）。

上边框左：主回合进行中是 `flame(3)` + “处理中” + 计时，回合结束按 `settleMark` 冷却成 ✓/✗ 约 1 秒后消失，暖光同步渐隐；
主会话 fire-review 进行中追加 `◈ 审查 k/n`（顾问、修复、总结相没有可数票数，只显示“◈ 审查”）。右：watcher 发布的“观察员”、
master 发布的“指挥官”，本模块直接组合发布串，不解析彩色串也不维护启用状态。下边框左：会话标题；右：模型/思考档、启用时的
Fast、上下文百分比/容量。上下文低占用为灰色，达到既有阈值才警告。

展示标题只属于外壳：正式会话名优先，否则取当前分支首条非空用户文本的前六个字素，超出加省略号；尚无文本显示“新会话”。
会话启动、切树、改名和用户消息开始时更新投影，消息落盘前即可显示，逐帧绘制不扫描历史。不写回会话名，不改变官方会话列表
或终端侧边栏。

`render.ts` 是唯一纯布局入口（`topBorder` / `bottomBorder`），按实际 `visibleWidth` 逐级退让，不保存状态：
- 上边框：观察员 → 审查字样 → “处理中”/“等待 N 个子代理” → 审查计数 → 指挥官；
- 上边框三态：指挥官生成中“处理中”；指挥官空闲但有在飞子代理（经 `busy.ts` 的 `watchBusy`）“等待 N 个子代理”，火苗继续转，计时自本轮人类输入起连续累计、被结果唤醒也不重置；定格只由 `watchBusy` 的歇下边沿触发（agent_settled 时在飞数为 0，或在飞数归零时指挥官已空闲），外壳不自己拼装判断。
- 下边框：标题 → 容量 → 模型名；上下文百分比与 Fast 尽量完整保留，连百分比也放不下时退成纯横线。

动效只经 `flame.ts` 的 `onFrame`：仅在回合进行、落定过渡或审查进行时订阅，其余时间时钟停止。审查进度来自 review 发布的占用频道 `herdr:blocked`：持有时的 payload 带活的 `progress` 访问器（占用按计数配对，进度变化不能靠重发 true），
外壳每次绘制调用它取 `k/n`，`active:false` 表示审查结束；审查锁编辑器时由
`review/ui.ts` 包住锁定前的编辑器，取它的上下边框并在中间放一行取消提示，外壳状态因此在审查期间保持可见。
